# Repository support

- [`release/`](release/README.md): active nonpublishing candidate build and verification tools.
- [`harness/`](harness/README.md): retained fault-harness material for the retired command surface.

The historical harness and [recordings](../docs/media/) were relocated without rewriting them.
Their embedded paths and examples describe the earlier layout and CLI, not a current execution or
cleanup procedure. Do not run the old scenarios or regenerate the recordings against the modern CLI.
